## Protocolo de Validación — Futuro

### Checklist Pre-Entrega (Para Evitar Duplicación)

**Antes de dar por completo un proyecto:**

1. [ ] **Crear inventario de tareas conceptuales** (qué temas se mencionaron)
2. [ ] **Mapear a documentos entregables** (dónde quedó documentado)
3. [ ] **Validar cobertura** (¿todas las tareas tienen entregable?)
4. [ ] **Identificar duplicadas** (¿algún tema está en 2+ lugares?)
5. [ ] **Actualizar Linear** (cambiar estados, agregar links a Drive)

### Auditoría Periódica (Mensual)

- Revisar todas las tareas de proyecto activo
- Identificar completadas vs. bloqueadas
- Consolidar duplicadas
- Actualizar descripciones a customer-facing
