# 🏛️ BRAND GUIDELINES - Bedrock Abogados

Especificación completa de identidad visual, tipografía, colores y aplicaciones.

## 1. IDENTIDAD VISUAL

### Logo Principal
- **Símbolo**: Pirámide geométrica con líneas limpias
- **Concepto**: Equilibrio, solidez, justicia, estructura
- **Construcción**: Triángulo sobre rectángulo con líneas internas
- **Aplicaciones**: Blanco sobre azul, dorado sobre beige, azul sobre blanco

### Variantes del Logo
```
Horizontal (recomendado para documentos)
Vertical (redes sociales)
Isotipo solo (favicon, thumbnails)
Negativo (sobre fondos oscuros)
```

## 3. TIPOGRAFÍA

### Familia Principal: NEXA BOLD
**Uso**: Títulos principales, headers H1, logotipo
```
Weight: Bold (700)
Tamaño: 48px - 72px
Tracking: 2-3px (letras espaciadas)
Ejemplo: BEDROCK ABOGADOS
```

### Familia Secundaria: MONTSERRAT
**Uso**: Subtítulos, headers H2-H3, highlights
```
Weight: Regular (400) | Bold (700)
Tamaño: 18px - 32px
Ejemplo: "Legal Balance"
```

### Familia de Texto: TINOS
**Uso**: Body text, párrafos, contenido
```
Weight: Regular (400) | Italic (400)
Tamaño: 11px - 14px (documentos)
Line-height: 1.6
Ejemplo: Lorem ipsum dolor sit amet...
```

## 4. ELEMENTOS VISUALES

### Formas Geométricas
- **Pirámides**: Símbolo principal, divisores
- **Círculos**: Elementos decorativos, avatares
- **Rectángulos**: Headers, bloques de contenido
- **Líneas**: Separadores horizontales

### Espacios en Blanco
- Márgenes: 40px (documentos), 20px (slides)
- Padding interno: 20-30px
- Espaciado entre bloques: 60px

### Fotografía
- Profesional, retratos corporativos
- Imágenes de justicia, tribunales, negocios
- B&N con acentos en color (Terracota/Azul)

## 5. APLICACIONES

### Documentos (DOCX)
```
Header: Azul primario + Logo + Línea dorada
Footer: Datos de contacto + Línea
Body: Tinos 11pt, line-height 1.6
Títulos: Nexa Bold 28pt
Subtítulos: Montserrat 14pt
Márgenes: 40px
```

### Presentaciones (Slides/PPTX)
```
Portada: Azul primario + Logo + Título Nexa Bold
Diapositivas: Blanco + Azul como acentos
Títulos: Nexa Bold 48pt
Contenido: Montserrat 24pt / Tinos 14pt
Colores: Máx 2 colores + blanco por slide
```

### Cartas/Letterhead
```
Header (80px altura):
├─ Línea azul (4px) - lado izquierdo
├─ Logo + Nombre + Tagline (centro)
└─ Línea dorada (2px) - abajo

Body: Márgenes 40px, Tinos 11pt

Footer:
├─ Línea azul (2px)
└─ Datos contacto + Redes (Montserrat 9pt)
```

### Email Signature
```
Formato: Tabla HTML 600px ancho
Header: Azul con dorado (gradiente)
Logo: 120px ancho
Nombre: Nexa Bold 16pt
Título: Montserrat 12pt, Terracota
Contacto: Tinos 10pt
```

### Tarjeta de Presentación
```
Frente:
├─ Azul primario 85% del espacio
├─ Logo + Nombre blanco
└─ Línea dorada

Reverso:
├─ Beige
├─ Título profesional
└─ Contactos
```

## 6. ESTILO DE CONTENIDO

### Tonalidad
- Profesional pero accesible
- Confiable y sólido
- Moderno dentro de lo tradicional
- Técnico pero elegante

### Composición
- Líneas limpias
- Espacios negativos generosos
- Máximo 2-3 colores por composición
- Simetría y balance

### Iconografía
- Líneas limpias
- Peso consistente (2-3px stroke)
- Colores: Azul primario o Terracota
- Tamaño: 24px mínimo

## 7. RESTRICCIONES Y PROHIBICIONES

❌ NO HACER:
- Cambiar colores del logo
- Usar tipografías diferentes sin autorización
- Mezclar más de 2 familias tipográficas
- Fondos fotográficos sin permission
- Logo pequeño (menos de 80px ancho)
- Colores no oficiales

✅ PERMITIDO:
- Variaciones de color del logo (blanco, dorado)
- Escalar proporcionalmente
- Elementos decorativos geométricos
- Combinaciones de color: Azul + Terracota / Azul + Beige
