## 🖥️ OPCIÓN 1: Mac Safari (RECOMENDADO)

### Paso 1: Abrir archivo
```
1. Finder → Propuestas Comerciales → jhonatan-londono-2025
2. Doble clic en: ANALISIS_BEDROCK_JHONATAN_LONDONO.html
3. Se abre en Safari automáticamente
```

### Paso 2: Exportar como PDF
```
1. Safari → Archivo (menú superior)
2. Clic en "Exportar como PDF..."
3. Aparece ventana de guardar
```

### Paso 3: Configurar PDF
```
En la ventana de guardar:
- Nombre: ANALISIS_BEDROCK_JHONATAN_LONDONO.pdf
- Ubicación: La misma carpeta (propuestas-comerciales/jhonatan-londono-2025)
- Formato: PDF (debe estar seleccionado)
- Clic en "Guardar"
```

✅ **PDF generado en 30 segundos**

## 💻 OPCIÓN 2: Mac Chrome o Firefox

### Paso 1: Abrir archivo
```
1. Abre el navegador (Chrome o Firefox)
2. Cmd + O (abrir archivo)
3. Navega a: propuestas-comerciales/jhonatan-londono-2025
4. Selecciona: ANALISIS_BEDROCK_JHONATAN_LONDONO.html
5. Abre
```

### Paso 2: Imprimir a PDF
```
1. Presiona: Cmd + P
2. Aparece la ventana de impresión
```

### Paso 3: Guardar como PDF
```
En la ventana de impresión:
- Arriba a la derecha: Aparece un dropdown (normalmente dice "Mostrar detalles")
- Haz clic en ese dropdown
- Selecciona: "Guardar como PDF"
- Elige nombre y carpeta
- Clic en "Guardar"
```

✅ **PDF generado en 30 segundos**

## ⌨️ OPCIÓN 4: Terminal (Mac/Linux con wkhtmltopdf)

### Paso 1: Instalar herramienta (si no la tienes)
```bash

```

### Paso 2: Generar PDF - Análisis
```bash

  "/Users/juanma/Documents/Bedrock IA/propuestas-comerciales/jhonatan-londono-2025/ANALISIS_BEDROCK_JHONATAN_LONDONO.html" \
```
