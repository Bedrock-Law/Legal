# 🔧 Shared Libraries - Utilidades Compartidas

Librerías reutilizables entre módulos: validadores, helpers, tipos y utilidades comunes.

## Módulos

- **Legal Validators** - Validadores de conceptos legales
- **Financial Helpers** - Utilidades financieras
- **Document Utils** - Utilidades de documentos
- **Types & Schemas** - Tipos compartidos y esquemas JSON Schema
- **Error Handling** - Manejo centralizado de errores

## 📦 Uso

```typescript
import { validateLegalEntity, calculateCompliance } from '@bedrock/shared-libs';
```
